# Alick-main Backend & Database Rules (`AGENTS.md`)

## 1. Execution Boundaries (Strict)
- **Local Files Only:** Only generate or edit local files under `supabase/migrations/`.
- **Never Touch Live Databases:** Do NOT run `supabase db push`, `supabase db reset`, `supabase link`, or inspect `.env*` files. The developer runs `supabase db push` manually after code review.
- **Skill Compliance:** Follow all rules in `.agents/skills/supabase-postgres-best-practices` (RLS enabled everywhere, FK indexes, `bigint` money, `timestamptz`, `text` over `varchar(n)`, `SET search_path = ''` on all `SECURITY DEFINER` and trigger functions).

## 2. Target Migration Files
1. `supabase/migrations/0001_initial_schema.sql` — Extensions, tables, constraints, triggers, indexes, and default-deny `ENABLE ROW LEVEL SECURITY`.
2. `supabase/migrations/0002_rls_grants_rpc_storage.sql` — Default privilege revocations, `private.is_admin()`, RLS policies, `SECURITY DEFINER` RPCs, and storage buckets.
3. `supabase/migrations/0003_seed_data.sql` — Initial seed data converted from existing static storefront arrays (converting whole Naira to minor-unit `bigint` kobo by multiplying by `100`).

## 3. Extensions, Money Units & Core Schema (`0001_initial_schema.sql`)
- **Extension:** Start with `CREATE EXTENSION IF NOT EXISTS pgcrypto WITH SCHEMA extensions;`.
- **Currency Unit:** Store ALL monetary values in minor-unit NGN kobo as `bigint` (`int8`), never `int4`, `numeric`, or floating-point types.
- **`public.user_roles`**:
  - `user_id uuid PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE`
  - `role text NOT NULL CHECK (role IN ('admin'))`
  - `created_at timestamptz NOT NULL DEFAULT now()`
- **`public.products`**:
  - `id uuid PRIMARY KEY DEFAULT gen_random_uuid()`, `slug text UNIQUE NOT NULL`, `name text NOT NULL`, `brand text`, `model text`, `description text`, `category text NOT NULL`, `tags text[] NOT NULL DEFAULT '{}'`, `price bigint NOT NULL CHECK (price >= 0 AND price <= 10000000000000)`, `retail_price bigint CHECK (retail_price IS NULL OR retail_price > 0)`, `compare_at_price bigint CHECK (compare_at_price IS NULL OR compare_at_price >= 0)`, `stock_quantity int NOT NULL DEFAULT 0 CHECK (stock_quantity >= 0)`, `specs jsonb NOT NULL DEFAULT '{}'::jsonb`, `images text[] NOT NULL DEFAULT '{}'`, `is_featured boolean NOT NULL DEFAULT false`, `is_active boolean NOT NULL DEFAULT true`, `created_at timestamptz NOT NULL DEFAULT now()`, `updated_at timestamptz NOT NULL DEFAULT now()`, plus table constraint `CHECK (retail_price IS NULL OR retail_price <= price)`.
  - `compare_at_price` is a plain strike-through price: seed it `NULL` unless strictly greater than `price`.
- **`public.flash_sales`**:
  - `id uuid PRIMARY KEY DEFAULT gen_random_uuid()`, `title text NOT NULL`, `product_id uuid NOT NULL REFERENCES public.products(id) ON DELETE CASCADE`, `sale_price bigint NOT NULL CHECK (sale_price > 0)`, `starts_at timestamptz NOT NULL`, `ends_at timestamptz NOT NULL CHECK (ends_at > starts_at)`, `is_active boolean NOT NULL DEFAULT true`, `created_at timestamptz NOT NULL DEFAULT now()`.
  - Trigger `trg_validate_flash_sale` (`BEFORE INSERT OR UPDATE`, `SET search_path = ''`): locks `public.products` row `FOR UPDATE`, raises an exception `IF NOT FOUND`, verifies `NEW.sale_price < v_price` **only when `NEW.is_active`** (so a stale sale can still be deactivated), and rejects overlapping `tstzrange(starts_at, ends_at, '[)')` rows on `public.flash_sales` **only** when `NEW.is_active = true` (filtering `product_id = NEW.product_id AND is_active = true AND id IS DISTINCT FROM NEW.id`).
  - Trigger `trg_guard_product_price` (`BEFORE UPDATE OF price` on `public.products`, `SET search_path = ''`): raises an exception if `NEW.price` is less than or equal to any active (`is_active = true AND ends_at > now()`) `sale_price` in `public.flash_sales` for `NEW.id`.
- **`public.site_banners`**:
  - `id uuid PRIMARY KEY DEFAULT gen_random_uuid()`, `slot text UNIQUE NOT NULL`, `headline text NOT NULL`, `subheadline text`, `cta_text text`, `cta_link text`, `media_urls text[] NOT NULL DEFAULT '{}'`, `metadata jsonb NOT NULL DEFAULT '{}'::jsonb`, `is_active boolean NOT NULL DEFAULT true`, `updated_at timestamptz NOT NULL DEFAULT now()`.
- **`public.site_settings`** (Single-Row Configuration):
  - `id boolean PRIMARY KEY DEFAULT true CHECK (id)`, `site_name text NOT NULL DEFAULT 'Alick System Services'`, `tagline text`, `phone text NOT NULL`, `email text NOT NULL`, `address text NOT NULL`, `whatsapp_number text NOT NULL`, `social_links jsonb NOT NULL DEFAULT '{}'::jsonb`, `shipping_rates jsonb NOT NULL DEFAULT '{"ikeja_pickup": 0, "lagos_delivery": 500000, "interstate_delivery": 1500000}'::jsonb`, `high_value_threshold bigint NOT NULL DEFAULT 50000000 CHECK (high_value_threshold >= 0)`, `updated_at timestamptz NOT NULL DEFAULT now()`.
- **`public.orders`**:
  - `id uuid PRIMARY KEY DEFAULT gen_random_uuid()`, `order_number text UNIQUE NOT NULL DEFAULT ('ALK-' || upper(encode(extensions.gen_random_bytes(6), 'hex')))`, `customer_name text NOT NULL CHECK (char_length(customer_name) BETWEEN 2 AND 120)`, `customer_email text NOT NULL CHECK (char_length(customer_email) <= 150)`, `customer_phone text NOT NULL CHECK (char_length(customer_phone) BETWEEN 7 AND 30)`, `shipping_zone text NOT NULL`, `shipping_address jsonb NOT NULL DEFAULT '{}'::jsonb`, `sales_mode text NOT NULL DEFAULT 'consumer' CHECK (sales_mode IN ('consumer', 'retail'))`, `notes text CHECK (notes IS NULL OR char_length(notes) <= 500)`, `subtotal bigint NOT NULL CHECK (subtotal >= 0)`, `shipping_fee bigint NOT NULL CHECK (shipping_fee >= 0)`, `total_amount bigint NOT NULL CHECK (total_amount > 0 AND total_amount = subtotal + shipping_fee)`, `currency text NOT NULL DEFAULT 'NGN' CHECK (currency = 'NGN')`, `payment_reference text UNIQUE`, `payment_status text NOT NULL DEFAULT 'pending' CHECK (payment_status IN ('pending', 'paid', 'paid_needs_review', 'failed', 'refunded'))`, `fulfillment_status text NOT NULL DEFAULT 'pending' CHECK (fulfillment_status IN ('pending', 'processing', 'shipped', 'delivered', 'cancelled'))`, `requires_review boolean NOT NULL DEFAULT false`, `tracking_code text`, `expires_at timestamptz NOT NULL DEFAULT (now() + interval '30 minutes')`, `created_at timestamptz NOT NULL DEFAULT now()`, plus table constraint `orders_paid_requires_reference CHECK (payment_status NOT IN ('paid', 'paid_needs_review', 'refunded') OR payment_reference IS NOT NULL)`.
  - Trigger `trg_guard_order_payment_status` (`BEFORE UPDATE OF payment_status`, SECURITY INVOKER, `SET search_path = ''`): `refunded` is terminal; allowed transitions are `pending -> paid | failed | paid_needs_review`, `failed -> paid_needs_review`, `paid -> refunded`, `paid_needs_review -> paid | refunded`. When `current_user = 'authenticated'` (an admin session) only `pending -> failed`, `paid_needs_review -> paid | refunded` and `paid -> refunded` are allowed; settling a pending order as paid is reserved for `fulfill_paid_order`. Manually resolving `paid_needs_review -> paid` does NOT adjust stock; the admin must correct `stock_quantity` by hand.
- **`public.order_items`**:
  - `id uuid PRIMARY KEY DEFAULT gen_random_uuid()`, `order_id uuid NOT NULL REFERENCES public.orders(id) ON DELETE CASCADE`, `product_id uuid NOT NULL REFERENCES public.products(id) ON DELETE RESTRICT`, `product_name text NOT NULL`, `sales_mode text NOT NULL DEFAULT 'consumer' CHECK (sales_mode IN ('consumer', 'retail'))`, `unit_price bigint NOT NULL CHECK (unit_price >= 0)`, `quantity int NOT NULL CHECK (quantity > 0)`, `UNIQUE (order_id, product_id)`.
- **`public.services`**:
  - `id uuid PRIMARY KEY DEFAULT gen_random_uuid()`, `slug text UNIQUE NOT NULL`, `title text NOT NULL`, `description text NOT NULL`, `starting_price bigint CHECK (starting_price IS NULL OR starting_price >= 0)`, `turnaround text`, `features text[] NOT NULL DEFAULT '{}'`, `icon text`, `image_url text`, `sort_order int NOT NULL DEFAULT 0`, `is_active boolean NOT NULL DEFAULT true`, `created_at timestamptz NOT NULL DEFAULT now()`.
- **`public.blog_posts`**:
  - `id uuid PRIMARY KEY DEFAULT gen_random_uuid()`, `slug text UNIQUE NOT NULL`, `title text NOT NULL`, `excerpt text`, `content text NOT NULL`, `cover_image text`, `author text NOT NULL DEFAULT 'Alick System Services'`, `category text`, `tags text[] NOT NULL DEFAULT '{}'`, `is_featured boolean NOT NULL DEFAULT false`, `published boolean NOT NULL DEFAULT false`, `published_at timestamptz`, `created_at timestamptz NOT NULL DEFAULT now()`, `updated_at timestamptz NOT NULL DEFAULT now()`.
- **`public.reviews`**:
  - `id uuid PRIMARY KEY DEFAULT gen_random_uuid()`, `product_id uuid REFERENCES public.products(id) ON DELETE SET NULL`, `author_name text NOT NULL CHECK (char_length(author_name) BETWEEN 2 AND 80)`, `rating int NOT NULL CHECK (rating BETWEEN 1 AND 5)`, `comment text NOT NULL CHECK (char_length(comment) BETWEEN 5 AND 1000)`, `image_url text`, `is_approved boolean NOT NULL DEFAULT false`, `created_at timestamptz NOT NULL DEFAULT now()`.
- **`public.contact_messages`**:
  - `id uuid PRIMARY KEY DEFAULT gen_random_uuid()`, `name text NOT NULL CHECK (char_length(name) BETWEEN 2 AND 100)`, `email text NOT NULL CHECK (char_length(email) <= 150)`, `phone text CHECK (phone IS NULL OR char_length(phone) <= 30)`, `subject text NOT NULL CHECK (char_length(subject) BETWEEN 2 AND 150)`, `message text NOT NULL CHECK (char_length(message) BETWEEN 10 AND 3000)`, `service_slug text CHECK (service_slug IS NULL OR char_length(service_slug) <= 100)`, `is_resolved boolean NOT NULL DEFAULT false`, `created_at timestamptz NOT NULL DEFAULT now()`.
- **`public.rate_limits`**:
  - `key text PRIMARY KEY`, `hits int NOT NULL DEFAULT 1`, `window_start timestamptz NOT NULL DEFAULT now()`.
- **Indexes:** Create B-tree indexes on all foreign keys (`flash_sales.product_id`, `order_items.order_id`, `order_items.product_id`, `reviews.product_id`) and composite lookup indexes on `products (category, is_active)`, `blog_posts (published, is_featured, published_at DESC)`, `flash_sales (is_active, starts_at, ends_at)`, `orders (payment_status, expires_at)`, `contact_messages (is_resolved, created_at DESC)`, `reviews (is_approved, created_at DESC)`, and `rate_limits (window_start)`.
- **Default-Deny RLS:** At the end of `0001_initial_schema.sql`, enable RLS (`ALTER TABLE public.<table_name> ENABLE ROW LEVEL SECURITY;`) on all 12 tables.

## 4. Security, Grants, RLS & RPCs (`0002_rls_grants_rpc_storage.sql`)
- **Zero-Default Exposure:**
  - Enable RLS on EVERY table in `public`.
  - Execute `REVOKE ALL ON ALL TABLES IN SCHEMA public FROM public, anon, authenticated;` and `REVOKE ALL ON ALL FUNCTIONS IN SCHEMA public FROM public, anon, authenticated;`.
  - Execute `ALTER DEFAULT PRIVILEGES IN SCHEMA public REVOKE ALL ON TABLES FROM public, anon, authenticated;` and `ALTER DEFAULT PRIVILEGES IN SCHEMA public REVOKE ALL ON FUNCTIONS FROM public, anon, authenticated;`.
- **Admin Helper (`private.is_admin()`):**
  - `CREATE SCHEMA IF NOT EXISTS private; REVOKE ALL ON SCHEMA private FROM public, anon; GRANT USAGE ON SCHEMA private TO authenticated;`
  - `SECURITY DEFINER`, `SET search_path = ''`: returns `true` iff `(select auth.uid()) IS NOT NULL AND (select auth.jwt()->>'aal') = 'aal2' AND EXISTS (SELECT 1 FROM public.user_roles WHERE user_id = (select auth.uid()) AND role = 'admin')`.
  - `REVOKE EXECUTE ON FUNCTION private.is_admin() FROM public, anon; GRANT EXECUTE ON FUNCTION private.is_admin() TO authenticated;`
- **RLS Policies:**
  - **CRITICAL:** Every admin policy MUST specify `TO authenticated` using `(select private.is_admin())` so `anon` never executes `private.is_admin()`.
  - Public `SELECT` on active/published/approved rows only (`products`, `flash_sales`, `site_banners`, `services`, `blog_posts`, `reviews`). `flash_sales` additionally requires `starts_at <= now() AND ends_at > now()`; `blog_posts` additionally requires `published_at IS NULL OR published_at <= now()`.
  - Public column-limited `SELECT` on `site_settings` (`id, site_name, tagline, phone, email, address, whatsapp_number, social_links, shipping_rates, updated_at`) so `high_value_threshold` is never exposed to `anon`. The `site_settings` public-read policy and column grant are **`anon` only** (`authenticated` holds table-level `SELECT` for admins, so the policy must not apply to it); storefront settings reads use the anon client or the server service role.
  - **Column-level grants only:** `authenticated` must NOT receive table-level `INSERT` on `reviews` or `contact_messages` (it would override the column-limited grants). Admin tables grant `INSERT, UPDATE, DELETE` to `authenticated` for `products, flash_sales, site_banners, services, blog_posts`; `reviews` gets `UPDATE, DELETE`; `contact_messages` gets `SELECT, UPDATE, DELETE` (admin must be able to read them).
  - `orders` / `order_items`: `authenticated` gets `SELECT` only, plus `GRANT UPDATE (payment_status, fulfillment_status, tracking_code, requires_review) ON public.orders`. `subtotal`, `shipping_fee`, `total_amount`, `payment_reference` and all of `order_items` are immutable to admins.
  - Public column-limited `INSERT` only on:
    - `reviews (product_id, author_name, rating, comment)` with RLS `WITH CHECK (is_approved = false AND (product_id IS NULL OR EXISTS (SELECT 1 FROM public.products p WHERE p.id = product_id AND p.is_active)))` so inactive/unknown product ids are rejected without an FK-error oracle (never grant `image_url` to `anon`).
    - `contact_messages (name, email, phone, subject, message, service_slug)` with RLS `WITH CHECK (is_resolved = false)`.
  - Zero `anon` or non-admin access to `user_roles`, `orders`, `order_items`, `contact_messages` (`SELECT`), or `rate_limits`.
- **Required `SECURITY DEFINER` RPCs (all `SET search_path = ''`, `REVOKE EXECUTE ... FROM PUBLIC, anon, authenticated`, `GRANT EXECUTE ... TO service_role`):**
  1. `public.create_checkout_order(p_items jsonb, p_sales_mode text, p_shipping_zone text, p_customer_name text, p_customer_email text, p_customer_phone text, p_shipping_address jsonb, p_notes text, p_payment_reference text DEFAULT NULL)` -> `returns table (order_id uuid, order_number text, total_amount bigint, currency text)`:
     - Aggregates duplicate `product_id`s in `p_items`, validates input with regex only (no casts): `p_items` must be a JSON array of 1..100 objects, each with a UUID-formatted `product_id` and `quantity` matching `^[1-9][0-9]{0,3}$`; `p_shipping_address` must be a JSON object `<= 4096` bytes; customer name (2..120), email (5..150, simple `x@y.z` shape, lower-cased), phone (7..30 chars of `0-9+() -`) and notes (`<= 500`) are trimmed and validated with clean messages before insert; `[[:cntrl:]]` characters in any text field are rejected; an empty `p_payment_reference` means none, a supplied one must match `^[A-Za-z0-9._=-]{1,100}$` and be unused; shipping rate values must match `^[0-9]{1,12}$`; rejects `> 25` distinct items after aggregation, enforces **per-product SKU** quantity bounds (`1..9` when `p_sales_mode = 'consumer'`, `10..100` when `p_sales_mode = 'retail'`), locks products (`ORDER BY id FOR UPDATE`), checks `is_active = true` and `stock_quantity >= total_qty`, calculates unit price (`consumer`: active `flash_sales.sale_price` if valid, else `price`; `retail`: `COALESCE(retail_price, price)`, and when a flash sale is active `least(sale_price, COALESCE(retail_price, price))`), validates `p_shipping_zone` exists in `site_settings.shipping_rates` with a non-negative integer value (raising an exception if invalid), sets `requires_review = (v_total_amount >= v_high_value_threshold)`, uses the `orders.order_number` table default (`'ALK-' || upper(encode(extensions.gen_random_bytes(6), 'hex'))`), and inserts `orders` + `order_items`.
  2. `public.fulfill_paid_order(p_order_id uuid, p_payment_reference text, p_paid_amount bigint, p_currency text)` -> `returns text`:
     - Take `pg_advisory_xact_lock(hashtextextended(reference, 0))` first so concurrent callers with one reference serialise. If the reference already belongs to a different order, return `'duplicate_reference'`.
     - Lock target `orders` row (`FOR UPDATE`). If not found, return `'not_found'`.
     - If `payment_status = 'refunded'`, return `'refunded'` without modifying the order.
      - If `payment_status IN ('paid', 'paid_needs_review')`: return `'already_paid'` when the stored `payment_reference` equals the incoming one (idempotent replay), otherwise `'duplicate_payment'` (second charge; caller must alert). Neither modifies the order.
      - If the order already holds a non-null `payment_reference` (bound at checkout) that differs from the incoming one, set `payment_status = 'paid_needs_review'` WITHOUT overwriting the bound reference and return `'reference_mismatch'` (caller must alert; the incoming reference is not stored).
     - If `p_paid_amount <> total_amount OR upper(p_currency) <> upper(currency)`, do NOT raise an exception; update `payment_status = 'paid_needs_review'`, `payment_reference = p_payment_reference`, and return `'amount_mismatch'`.
     - Only proceed to stock deduction when `payment_status = 'pending' AND fulfillment_status <> 'cancelled'`. If `payment_status = 'failed'` or `fulfillment_status = 'cancelled'` or `now() > expires_at`, update `payment_status = 'paid_needs_review'`, `payment_reference = p_payment_reference`, and return `'paid_needs_review'`.
     - Lock all `products` referenced in `order_items` (`ORDER BY product_id FOR UPDATE`). If any item has `stock_quantity < quantity`, update `payment_status = 'paid_needs_review'`, `payment_reference = p_payment_reference` and return `'paid_needs_review'`.
     - Otherwise decrement `products.stock_quantity`, update `orders.payment_status = 'paid'`, `payment_reference = p_payment_reference`, and return `'paid'`.
  3. `public.get_guest_order(p_order_number text, p_email text)` -> `returns jsonb`:
     - Matches `order_number = upper(btrim(p_order_number))` and `customer_email = lower(btrim(p_email))` (columns are stored normalised, so no function wraps the columns and the index stays usable); the server must `check_rate_limit` per IP and per order number before each call; returns ONLY `order_number`, `payment_status`, `fulfillment_status`, `tracking_code`, `total_amount`, `currency`, `created_at`, and item `{ product_name, quantity, unit_price }` (never `shipping_address` or `customer_phone`).
  4. `public.check_rate_limit(p_key text, p_max_hits int, p_window_seconds int)` -> `returns boolean`:
     - Rejects keys that are empty or longer than 200 characters, `p_max_hits` outside `1..1000000` and `p_window_seconds` outside `1..86400`. Every call first deletes up to 25 rows with `window_start < now() - interval '1 day'` (`ORDER BY window_start ... FOR UPDATE SKIP LOCKED`) so unique-key floods cannot outgrow cleanup. Atomic upsert resetting `hits = 1` when `now() - window_start >= make_interval(secs => p_window_seconds)`, otherwise `hits = least(hits + 1, 1000000)`, returning `hits <= p_max_hits`.
  5. `public.purge_rate_limits()` -> `returns integer` (same SECURITY DEFINER / `service_role`-only pattern): deletes `rate_limits` rows with `window_start < now() - interval '1 day'` and returns the count; schedule hourly (pg_cron or a server cron route).
- **Trigger functions** need no `EXECUTE` grant to `authenticated` (privilege is checked only at trigger creation).
- **Seed data (`0003`):** Every table uses `ON CONFLICT DO NOTHING` on its natural key so re-runs never overwrite live stock, prices, settings or admin-edited content; the `flash_sales` seed joins `products` and skips (never fails) when the product is gone, its price is `<=` the sale price, or an overlapping active sale exists. Blog seed `content` stays `<p>…</p>` HTML until the Stage 4 Markdown migration.
- **Storage Buckets (`product-media`, `blog-media`):**
  - `public = true`, `file_size_limit = 5242880`, `allowed_mime_types = ARRAY['image/jpeg', 'image/png', 'image/webp']`.
  - `storage.objects` policies (`SELECT`, `INSERT`, `UPDATE`, `DELETE`) restricted to `TO authenticated` with `(select private.is_admin())` (no `anon` directory listing). `INSERT` and `UPDATE ... WITH CHECK` additionally require `name ~* '^[a-z0-9][a-z0-9/_.-]{0,200}\.(jpe?g|png|webp)$' AND name !~ '\.\.'` (image extensions only, safe charset, no `..`), because the MIME allow-list trusts the client-declared Content-Type.
